# learning-path

A Claude Code skill that takes you through a technology (Java, Python, Docker, anything) from beginner to expert, one topic at a time. Progress is saved in plain files, so you can open Claude Code on any day and resume exactly where you stopped.

## How it works

Each topic follows the same six steps:

1. Roadmap: Claude builds a leveled topic list for the technology, checked against official sources, and saves it. It refreshes itself when it is more than 30 days old.
2. Learn: a short explanation with a small code example, then a 3 to 5 question quiz. The score is never a gate.
3. Brainstorm: Claude suggests 2 or 3 small project ideas (or you bring your own), writes a spec with acceptance criteria, and creates the topic folder with build setup only.
4. Build: you write the code. Claude waits, and can give a hint to get started.
5. Review: Claude builds and tests your code, then gives hints grouped by spec, topic use, quality and best practices. It never hands you the fix up front; you can ask to see the fix for one hint at a time.
6. Track: the topic is marked done (or done with an override if you skip a passing review) and progress is updated.

## Install

Link the skill so edits in this repo take effect immediately:

```bash
ln -s "$PWD/skill/learning-path" ~/.claude/skills/learning-path
```

Or copy it instead:

```bash
cp -r skill/learning-path ~/.claude/skills/learning-path
```

## Commands

| Command | What it does |
|---|---|
| `/learning-path <technology>` | Start a new roadmap, or continue an existing one |
| `/learning-path` | Continue the most recently active roadmap |
| `/learning-path refresh` | Refresh the current roadmap now |
| `/learning-path status` | Show the roadmap and progress |

## Your `learning/` folder

Everything is created in the folder where you run Claude Code:

```
learning/
  index.md              all roadmaps: progress, current topic, last active
  java/
    roadmap.md          topics, levels, status and stage (single source of truth)
    specs/
      03-collections.md
    code/
      03-collections/   build setup only (pom.xml, empty src folders); you write the code
```

One folder per technology, so switching never touches another roadmap. Claude never overwrites your files, and an existing topic folder is reused as is. `index.md` is a summary and can be rebuilt from the roadmap folders.

## About roadmap.sh

Roadmaps are generated by Claude, not copied. roadmap.sh is linked for you to view personally only; its content is never copied or scraped.

## Running the tests

Prerequisites: the `claude` CLI, Java and Maven, and Python with pytest.

```bash
bash tests/run-all.sh --repeat 2
```

Each scenario in `tests/scenarios/` makes real `claude -p` calls, so a full run takes a long time. Run one scenario with `bash tests/run-scenario.sh tests/scenarios/<dir>`. Fixture dates use a `__TODAY__` token that the runner replaces with the current date.

Without network access to Maven Central, the review cannot download dependencies and falls back to its offline path (compiling with `javac` and reading the code).
